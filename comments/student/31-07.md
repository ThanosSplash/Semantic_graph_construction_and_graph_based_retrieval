### Σημαντικό bug στον χειρισμό αποτυχίας retrieval

Όταν δεν βρίσκεται relevant passage, το rank αποθηκεύεται ως `-1`. Στη σύγκριση μετατρέπεται σε `0`.
```text
def RR_score(predictions, correct_results, k):
    # Function that calculates the rank score
    correct_set = set(correct_results)
    for indx, prediction in enumerate(predictions):
        if prediction in correct_set:
            return 1/(indx + 1), indx

    return 0, 9999
Στο αρχειο evaluation.py αλλαξα την τιμη που επιστρεφει σε κατι πολυ μεγαλο    
αρχικα το ειχα σαν κ+1 αλλα αυτο εκανε προβληματα στην κατασκεσυη του table
```

```text
def normalize_dict(scores):
    keys = list(scores.keys())
    values = np.array(list(scores.values()), dtype=float).reshape(-1, 1)

    scaler = MinMaxScaler()
    normalized = scaler.fit_transform(values).flatten()

    return dict(zip(keys, normalized))
```
